한국어 보고서 초안과 메모를 보고서 문체로 정리하는 스킬 `dorami-report-fmt`를 만들었습니다. 한국어로는 **도라미 보고서체**라고 부릅니다. FMT는 *Fit My Tone*의 약자입니다.

이 글에서는 스킬에 어떤 작성 기준을 담았는지, 여러 AI 도구에서 사용할 수 있도록 저장소를 어떻게 구성했는지 정리합니다.

## 스킬의 목적

`dorami-report-fmt`는 한국어 보고서 초안, 메모, 문장을 자연스럽고 객관적인 보고서체로 다듬습니다. 문장 표현뿐 아니라 제목, 문단 흐름, 보고서 구조도 함께 정리할 수 있습니다.

작성할 때 가장 먼저 지키도록 한 기준은 **사용자가 제공한 사실과 의미를 유지하는 것**입니다. 원문에 없는 사실, 통계, 사례, 출처를 임의로 추가하지 않습니다. 정보가 부족한 경우에는 추측해 채우기보다 확인하거나 신중하게 표현하도록 했습니다.

## 문장과 문단 정리 기준

스킬에는 어색한 문장과 번역투, 반복되는 문장 구조를 줄이는 기준을 넣었습니다. 주제와 바로 연결되지 않는 상투적인 도입은 피하고, 과장된 표현이나 같은 연결어와 종결어미의 반복도 줄이도록 했습니다.

문단의 순서는 주제에 따라 정리합니다.

- 정책·보안·기술 주제: 정의 → 현황 → 문제점·위험 → 개선방안·관리기준
- 시나리오형 내용: 환경 → 흐름 → 영향 → 대응 방안
- 체크리스트형 내용: 점검 대상 → 위험 요소 → 확인 기준 → 대응 조치

이 순서는 모든 글에 기계적으로 적용하는 형식이 아니라, 초안의 내용과 요청한 보고서 구조에 맞춰 참고하는 기준입니다. 사용자가 문체만 고쳐 달라고 하면 제목이나 문단 순서는 필요한 만큼만 바꾸고, 구조 정리를 요청한 경우에는 전체 흐름을 조정합니다.

## 여러 AI 도구에서 사용하는 방법

저장소에는 스킬 원본과 도구별 사용 파일을 함께 두었습니다.

- `skills/dorami-report-fmt/`: 스킬 원본과 참고 문서
- `.agents/skills/dorami-report-fmt/`: Codex용 프로젝트 스킬
- `.claude/skills/dorami-report-fmt/`: Claude Code용 프로젝트 스킬
- `prompts/`: 프롬프트 파일
- `portable/`: 단일 파일 버전
- `tools/`: 문체 추출과 참고 자료 준비 등에 쓰는 개발 도구
- `tests/`: 검사 도구의 테스트

Codex와 Claude Code에는 설치 스크립트를 사용할 수 있습니다.

```bash
./install.sh --codex
./install.sh --claude
./install.sh --all
```

설치된 파일을 갱신하는 `update.sh`와 제거하는 `uninstall.sh`도 포함했습니다. Gajae Code와 일반 AI 도구에서는 `prompts/` 또는 `portable/`의 파일을 활용할 수 있습니다.

사용할 때는 다음과 같이 요청할 수 있습니다.

```text
이 초안을 도라미 보고서체로 다듬어줘.
AI식 상투 표현은 줄이고, 객관적인 보고서 문체로 정리해줘.
내용은 임의로 추가하지 말고 문장 흐름과 표현만 다듬어줘.

[초안 붙여넣기]
```

## 참고 자료와 개인정보 관리

문체 추출과 스킬 개선 방법은 일반 사용용 스킬 파일과 분리해 `references/`에 정리했습니다. 여기에는 문체 추출 과정, 보고서 구조와 표현 기준, 피해야 할 표현, 로컬 참고 자료 관리, 벤치마크 기준이 포함되어 있습니다.

실제 보고서 원문이나 변환 예시는 공개 저장소에 포함하지 않는 것을 기준으로 삼았습니다. 개인 참고 자료는 로컬의 `private/`에서 관리하고, `.gitignore`에도 해당 경로와 HWP·HWPX 파일 형식을 추가하도록 안내합니다. 설치와 업데이트 스크립트 역시 `private/` 내용을 복사하지 않습니다.

공개 파일을 점검하는 스크립트도 두 가지 마련했습니다.

- `validate_skill.py`는 필수 파일과 스킬 진입 파일의 동기화 여부 등을 확인합니다.
- `privacy_check.py`는 공개 파일에서 이메일, 전화번호, 학번처럼 개인정보일 수 있는 패턴과 보고서 예시로 의심되는 파일을 검사합니다.

이 스크립트는 정해진 패턴과 파일 구조를 확인하는 도구입니다. 모든 개인정보나 공개 위험을 빠짐없이 찾아낸다는 의미는 아닙니다.

## 벤치마크 기준

`benchmark-guide.md`에는 여러 처리 순서를 비교하는 방법과 평가 기준을 정리했습니다. 평가 항목은 의미 보존 30점, 보고서체 적합도 25점, 도라미체 유사도 20점, AI식 표현 감소 15점, 과잉 수정 여부 10점입니다.

이 문서는 스킬을 점검할 때 사용할 **평가 기준과 비교 절차**를 설명합니다. 저장소에 평가 기준이 있다는 사실이 실제 벤치마크 결과나 성능 향상을 의미하지는 않습니다.

## 저장소

`dorami-report-fmt`는 한국어 보고서 초안을 다듬는 스킬과 프롬프트, 설치 파일, 개발 참고 자료, 공개 파일 검사 도구를 정리한 프로젝트입니다.

자세한 파일 구성과 사용 방법은 [GitHub 저장소](https://github.com/Clotilde030603/dorami-report-fmt)에서 확인할 수 있습니다.
